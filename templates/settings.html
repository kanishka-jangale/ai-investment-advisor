Privacy & account

The app stores only what you type: a username and password hash (if you register), profile answers, holdings, scenarios, watchlist and reminders, in a local SQLite file. Sessions use a signed cookie. Never enter bank, broker or ID details.

Everything in this app is educational material, not individualised financial advice. It is not a licensed adviser, broker or trading system, and it never guarantees returns.

Glossary

How the calculations work

  • Current value = quantity x latest price
  • Cost basis = quantity x purchase price
  • Unrealized P/L = current value - cost basis (before fees and taxes)
  • Return % = P/L / cost basis x 100 (cost basis must be above 0)
  • Weight % = holding value / total portfolio value x 100
  • Period return % = (ending value - starting value) / starting value x 100
  • Volatility = standard deviation of daily returns x sqrt(252)
  • Max drawdown = largest fall from a previous peak
  • SIP = target / [((1+i)^n - 1) / i x (1+i)], i = annual rate / 12, n = months (payments at start of month)
  • Risk score = average of 8 factors (each 1-5 points scaled to 0-100). Under 35 Conservative, 35 to 65 Moderate, 65 and above Aggressive.

Sample walkthrough

  1. Open the demo and choose a sample investor.
  2. Complete the Risk Profile questionnaire and read the explanation.
  3. Open My Portfolio and inspect value, allocation and performance.
  4. Add or edit a holding and watch the totals recalculate.
  5. Open AI Insights and expand "Why did this appear?" on each card.
  6. Compare two hypothetical allocations, or try the Goal Planner.
  7. Open Reports, print or save as PDF, and note the data sources and assumptions.
